# Byungchan Hwang · Personal Homepage

CV 내용을 반영한 GitHub Pages용 정적 홈페이지입니다.

- index.html: 소개, 학력, 연구, 프로젝트, 수상 및 활동
- paper.html: 논문 소개와 브라우저 내장 PDF 뷰어
- assets/marl-nonstationary-markets.pdf: 제공받은 원본 논문 (수정 없음)
- style.css: 반응형 스타일

## GitHub Pages 공개
HanyangChan 계정의 HanyangChan.github.io 저장소 최상위에 이 폴더 안의 파일과 assets 폴더를 올리세요. Settings → Pages에서 Deploy from a branch, main, /(root)를 선택하세요. 기존 저장소가 있다면 기존 내용을 확인한 뒤 반영하세요.

## 논문 교체
assets의 PDF를 같은 파일명으로 교체하면 됩니다. 다른 파일명을 사용하면 paper.html과 index.html의 PDF 경로를 함께 수정하세요. PDF는 웹사이트에 포함되므로 arXiv 계정이나 외부 PDF 서비스가 필요하지 않습니다. 브라우저가 PDF 임베드를 지원하지 않으면 직접 열기/다운로드 링크를 사용합니다.

CV 원본은 연락처 등 공개 범위를 추가로 선택할 수 있도록 포함하지 않았습니다. 웹사이트에는 이메일과 CV에 기재된 GitHub·블로그 주소를 사용했습니다. 이력의 Present 표기는 제공된 2026년 6월 CV 기준입니다.
