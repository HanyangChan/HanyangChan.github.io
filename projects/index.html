Agent Memory Manager: Robust Long-Term Memory for LLM Agents

Team project · Sep. 2026 — Present

Designed an adaptive long-term memory framework for LLM agents that handles memory staleness, contradiction resolution, and constraint preservation. The pipeline supports CREATE, UPDATE, MERGE, and FORGET operations with temporal version tracking.

02 / PROJECT

Adaptive Fair Diffusion: Improving the Fairness–Quality Trade-off

Personal project · Jun. 2026

Extended Fair Diffusion with step-aware guidance and latent-space adaptive control. Orthogonal projection preserves prompt semantics, while conflict-aware dynamic weighting improves fairness only when guidance directions disagree.

Compared with the no-guidance baseline, Adaptive Dynamic Weight improved fairness by 36.8%, while Adaptive Orthogonal improved fairness by 26.3% with only a 1.9% reduction in CLIP quality.
